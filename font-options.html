Implementation note: The game targets self-hosted web fonts in src/fonts/ to avoid CDN dependency issues over Tailscale. If you choose a new font here, it must be added to the repo as local font files and loaded via @font-face in src/template.html.
Google Fonts fallback: Playfair Display, Libre Baskerville, Lora, Cormorant Garamond, and Source Serif 4 are all available from Google Fonts and work well for historical-period UI. Georgia is a safe system-only fallback with no network dependency.
